# S13.1 — First Live Event Activation Readiness

## Purpose
Prepare event-intake control for the first actual authorized rain event. This stage does not assert that rain has occurred and does not create a harvest observation.

## Preconditions
- S12.17 human field authorization exists.
- Authorized physical site identity is available.
- Authorized operator role is available.
- Approved source, instrument and video registers are available.
- No material S12 exception blocks field execution.

## Activation procedure
1. Resolve the current authorization reference and scope.
2. Bind the event to the actual authorized physical site.
3. Record the authorized operator role without inventing personnel identity.
4. Create a unique event identifier for the event being prepared.
5. Confirm approved rainfall/weather sources, measurement devices and video devices.
6. Record the actual activation timestamp only when the authorized event genuinely begins.
7. Preserve evidence classes: forecast remains forecast; source observation remains observation; field measurement remains measurement; derived DMRV metric remains derived; control-test record remains synthetic.

## Fail-closed
Do not activate if authorization, site identity, operator authority, source provenance, device identity or event identity is unresolved.

## Output
A controlled event-intake record in ACTIVATED state only when the actual authorized event begins.

## Current declaration
The repository contains no S13.1 live event and no field observation. This implementation is readiness/control logic only.
