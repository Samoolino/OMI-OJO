# FIN-001 — Financial Model Logic

**State:** S2 — SPECIFIED

## Core unit-economics control

The baseline model may use **400 L/pod/month** as a planning assumption, but the assumption is explicitly unverified until WAT-002B is supported by location-matched rainfall data and field telemetry.

## Required model variables

- deployed pods;
- collection area per pod;
- gross rainfall;
- event count;
- first-flush loss;
- environmental/QC rejection;
- storage limitation;
- usable/delivered liters;
- realized revenue per liter or service unit;
- operating cost per pod;
- cartridge/logistics cost;
- maintenance and replacement cost;
- data-service revenue;
- verification/audit costs.

## Bankability rule

Investor-facing base-case production must use an evidence-backed value. The 400 L figure remains a scenario variable until the validation gate is passed.
