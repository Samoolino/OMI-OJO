# ESG Evidence & Reporting Schedule

## Purpose

Connect investor capital deployment to auditable environmental activity without treating ESG metrics as guaranteed financial returns.

## Reporting cycle

1. Capital closing
2. Monthly operational evidence
3. Quarterly ESG/DMRV report
4. Periodic independent verification where applicable
5. Annual investment-grade ESG report
6. Financing-event cap-table and SAFE conversion update

## Capital-to-impact chain

`CAPITAL → DEPLOYMENT → PROJECT ACTIVITY → ENVIRONMENTAL EVIDENCE → DMRV → ESG REPORT → INVESTOR DISCLOSURE`

## Minimum evidence fields

- event/activity ID
- timestamp
- location reference
- source
- measurement/model classification
- methodology/version
- raw evidence reference
- transformation/calculation record
- evidence hash
- verification status
- responsible reviewer

## Claim controls

The DApp must not infer a carbon credit, avoided emission, potable-water status, or other regulated/environmental claim merely from collection activity. Claims require the applicable methodology, activity data, calculation and verification pathway.

## Investor access

Investor-facing evidence should be permissioned and should exclude credentials, private keys, unnecessary personal information and other protected data.
