# Grants, Network & Blockchain Strategy

## Core principle

Grant engagements fund measurable platform work packages. Network/blockchain infrastructure makes evidence portable and auditable. Neither is the environmental truth layer.

```text
Grant -> Work Package -> Product Capability -> Milestone -> Evidence -> Acceptance -> Release
                                      |
                                      v
                              Network / Integrity
                                      |
                              Deterministic Anchor
```

## Grant work-package pattern

Typical work packages:

1. dMRV engine
2. climate/environmental data infrastructure
3. blockchain integrity service
4. physical/field validation
5. ESG/GHG calculation and reporting
6. global deployment adapters
7. institutional/VDR infrastructure

Each package must define scope, deliverables, acceptance criteria, evidence, dependencies, release state and funding status.

## Network architecture

```text
Project / Site / Node / Evidence
          -> OMI-OJO Network Registry
          -> Anchor Adapter
          -> selected network/environment
          -> transaction / proof
          -> public verification
```

The evidence package remains chain-agnostic. Network adapters are replaceable.

## Blockchain boundary

Blockchain can provide integrity, timestamping, reproducibility and verification of an anchored deterministic root. It cannot establish environmental truth, water quality, ESG compliance, regulatory approval or grant funding.

## Funding boundary

Technical readiness and funding award are separate states. Builder/testnet/gas resources are infrastructure resources. Project-token status remains deferred unless separately approved.

## Required network products

- Network Registry
- Anchor Adapter Interface
- Anchor Registry
- Public Verification Portal
- Transaction/Proof Audit Log
- Contract Version Registry
- Security Review Register

## Institutional outputs

The same accepted evidence should support:

- grant reports
- investor/VDR packs
- ESG/GHG reporting
- regulatory submissions
- audit packages
- public verification

This avoids creating separate evidence truths for different funders or audiences.
