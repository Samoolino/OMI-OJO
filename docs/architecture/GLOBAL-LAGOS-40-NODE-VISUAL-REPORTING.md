# Global Lagos 40-Node Visual + Geospatial Reporting Contract

## Purpose

Turn the 40-node Lagos pilot into a project-landing reporting surface where each jurisdiction is independently inspectable.

The canonical node set is:

- 37 LCDA reference nodes
- Lagos House / Governor's Residence — generalized public-site treatment
- Governor's Office / Lagos State Secretariat
- NCF Lekki Conservation Centre

## Geospatial rule

A public landmark coordinate is a **candidate visual/geospatial reference**, not an authorized project-site coordinate.

Promotion path:

`jurisdiction description -> public landmark reference -> map/image cross-check -> candidate coordinate -> authorized GIS/site survey -> site registry AUTHORIZED -> source orchestration`

No candidate coordinate may be promoted automatically.

## Visual rule

Each node slide exposes:

1. jurisdiction and parent LGA;
2. landmark/site description;
3. candidate coordinate where public sources support one;
4. online visual-search surface;
5. map inspection surface;
6. visual-validation state;
7. live/public visual feed mode;
8. environmental evidence state.

Public images, map tiles, street imagery, videos and web pages are contextual visual references. They are not themselves environmental measurements.

## Current researched examples

- Orile-Agege: public sources identify the LCDA Secretariat and published coordinates around 6.62599, 3.3054; retain as candidate only.
- Ifelodun: official LCDA material identifies 3 Dispensary Street, Mosafejo, Amukoko; published public references place the area around 6.46, 3.34; retain as candidate only.
- Igando-Ikotun: LSETF identifies the Ikotun Secretariat Complex near Ikotun Market and publishes 6.54, 3.26.
- Apapa-Iganmu: public directory material publishes an HQ reference around 6.4481, 3.3591.
- Ikorodu North/West, Imota and Ikosi-Isheri have public location references used as candidate anchors.
- Lekki Conservation Centre has multiple public coordinate references clustered around 6.436–6.441 N, 3.535–3.536 E; the landing uses 6.43639, 3.53556 as a candidate public landmark reference.
- Lagos State Secretariat, Alausa has a public coordinate reference around 6.619578, 3.360282.

These values remain outside the authorized site registry until independently accepted.

## UI/UX structure

`Project Landing -> Lagos Pilot -> 40-node index -> node scroll slide -> visual/map references -> infrastructure definitions -> evidence/DMRV -> ESG/GHG -> release gates`

Infrastructure definitions should remain connected to each node rather than becoming detached marketing content:

- jurisdiction / governance;
- rainfall and climate indicators;
- water infrastructure;
- collection/measurement infrastructure;
- air-quality and satellite sources;
- sensor identity/calibration;
- QMS / water quality;
- video evidence;
- dMRV evidence package;
- ESG/GHG reporting;
- review/release state.

## Important discrepancy resolved

The pilot configuration previously named the third state-level node as Lagos State House of Assembly while the canonical 40-node venue registry named NCF Lekki Conservation Centre. The pilot configuration is now aligned to the canonical registry.
