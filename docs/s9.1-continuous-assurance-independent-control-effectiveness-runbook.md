# S9.1 — Continuous Assurance and Independent Control Effectiveness

## Objective
Test whether the controls defined for governed scale are actually operating effectively, rather than treating implementation or documentation as evidence of effectiveness.

## Assurance cycle
**CONTROL INVENTORY → SIGNAL COLLECTION → AUTOMATED RECONCILIATION → EXCEPTION TRIAGE → OWNER ATTESTATION → INDEPENDENT SAMPLE REVIEW → EFFECTIVENESS ASSESSMENT → CAPA → CLAIM REVIEW → RECERTIFICATION**

## Evidence hierarchy
Implementation evidence demonstrates that a control exists. Operating evidence demonstrates that it operated for a defined scope and period. Independent review assesses whether the evidence supports the control conclusion.

Control-owner attestation never substitutes for independent review where independence is required.

## Sampling
Samples must identify:
- site;
- control domain;
- review period;
- evidence class;
- exception history.

A material failure expands the review scope and can place affected scope into HOLD or SUSPENDED.

## Independence
Every independent review records reviewer authority and conflict status. Review references immutable evidence identifiers and a defined evidence scope.

## Effectiveness outcomes

**EFFECTIVE** — sampled operating evidence supports effective operation for the reviewed scope.

**EFFECTIVE_WITH_OBSERVATIONS** — control operates but observations require monitoring.

**IMPROVEMENT_REQUIRED** — corrective action is required.

**INEFFECTIVE** — control failure materially affects assurance.

**SUSPENDED** — operation is paused pending authorized remediation.

These outcomes do not establish premium status, product release, regulatory approval or environmental-performance certification.
