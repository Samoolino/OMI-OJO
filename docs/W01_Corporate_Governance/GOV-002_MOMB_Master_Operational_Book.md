# GOV-002 — MOMB Master Operational Book

**State:** S2 — SPECIFIED

## Operating objective

Create one controlled operating framework for governance, water harvesting, QMS, telemetry, logistics, DMRV, finance evidence and ecological reporting.

## Control principles

1. Every operational activity has an owner, input, output and evidence record.
2. Hardware and water-quality releases require QMS evidence.
3. Forecasts trigger preparation only; telemetry confirms actual events.
4. Financial assumptions are versioned and traceable to technical evidence.
5. Exceptions are logged and cannot be silently overwritten.
6. Production status and verification status are separate fields.

## Minimum operational states

`DESIGNED → SPECIFIED → IMPLEMENTED → VERIFIED → OPERATIONAL → RETIRED`

## Evidence package

Each material claim should link to: source dataset, calculation/model version, timestamp, responsible reviewer, exception record and approval state.
