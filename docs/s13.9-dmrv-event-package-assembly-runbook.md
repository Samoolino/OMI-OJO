# S13.9 — DMRV Event Package Assembly

## Purpose
Assemble the evidence and lineage package for one actual S13 field event after batch/seal traceability is reconciled.

The package organizes evidence; it does not create environmental observations.

## Procedure
1. Confirm S13.8 batch/sample/event traceability.
2. Freeze the event scope and reporting population.
3. Register each evidence item with type, source, timestamp and linkage.
4. Reconcile source provenance and field measurement identity.
5. Link video, custody, QMS and batch records to the same event.
6. Register the applicable methodology, organizational/operational boundaries and factor versions.
7. Calculate DMRV-derived metrics only where the required inputs and method are present.
8. Preserve input lineage for every derived value.
9. Record exceptions and unresolved limitations.
10. Compute and store a package digest for integrity control.
11. Lock the package for S13.10 evidence reconciliation.

## Evidence boundary
A DMRV package is an evidence container and lineage record. It is not an observation, verification, certification, premium-condition decision or product release.

A digest or blockchain anchor can demonstrate integrity of the referenced package; it does not establish environmental truth.

## Fail-closed
Hold the package when evidence lineage, provenance, methodology, boundary, factor version, or material exceptions remain unresolved. Do not substitute forecast values, model grids, API availability, synthetic values, or administrative nodes for actual event evidence.
