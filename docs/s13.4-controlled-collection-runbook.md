# S13.4 — Controlled Collection

## Purpose
Control the first authorized collection after first-flush diversion, recording actual collection activity and measurement without inventing field observations.

This gate does not establish water quality, laboratory status, premium condition, regulatory approval, or product release.

## Preconditions
- S13.3 has actually reached DIVERSION_COMPLETE for the same event.
- Event identifier and physical site are resolved.
- Collector identity is resolved.
- Authorized operator is present.
- Required measurement device is identified and available.

## Procedure
1. Reconcile the completed first-flush diversion record.
2. Confirm the same event identifier and physical site.
3. Record the actual controlled-collection start timestamp.
4. Conduct collection through the approved collector path.
5. Record the actual collection measurement using the identified instrument.
6. Capture event-linked video or approved equivalent evidence where required.
7. Record the actual collection end timestamp.
8. Reconcile measurement, timestamps, collector identity and evidence linkage.
9. Place the event on HOLD if any material requirement fails.
10. Authorize sample identification/chain-of-custody only after the collection record is internally reconciled.

## Evidence boundary
Forecast data remains forecast. Weather-source observations remain source observations. Collection activity is field-operation evidence. Actual quantity readings are instrument measurements. Video is evidence only when linked to the event and physical site. Synthetic values remain control-test records.

A collection measurement is not a laboratory result and does not by itself establish water quality, premium condition, environmental performance, or release eligibility.

## Fail-closed
Do not proceed to sample handoff when diversion completion is missing, event/site identity is unresolved, measurement provenance is incomplete, actual collection measurement is unavailable or untrusted, required event evidence is missing, or a material exception remains unresolved.

## Current declaration
No S13.4 live collection is claimed by this implementation. No collection volume, sample, laboratory result, premium determination, or environmental performance value is fabricated.
