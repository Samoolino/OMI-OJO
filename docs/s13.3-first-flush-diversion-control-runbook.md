# S13.3 — First-Flush Diversion Control

## Purpose
Control and evidence first-flush diversion during the actual authorized rain event before any water enters the controlled collection stage.

This gate does not establish water quality, harvest volume, premium status, laboratory results, or product release.

## Preconditions
- S13.2 site check has actually passed for the event.
- Event identifier and physical site are resolved.
- Authorized operator is present.
- First-flush diversion path is available and identified.

## Procedure
1. Confirm the event identifier and physical site.
2. Confirm the installed diversion path and its identity.
3. Activate diversion only during the actual authorized event.
4. Record actual diversion start time.
5. Maintain diversion according to the approved field procedure.
6. Record actual diversion completion time and operator confirmation.
7. Capture event-linked video or the approved equivalent evidence.
8. Reconcile the evidence before authorizing controlled collection.
9. Place the event on HOLD if any material control or evidence requirement fails.

## Evidence boundary
- Forecast remains forecast.
- Weather-source observations remain source observations.
- Diversion activity is field-operation evidence.
- Any actual instrument reading remains an instrument measurement.
- Video is evidence only when linked to the event and physical site.
- Synthetic values remain control-test evidence.

First-flush diversion evidence does **not** prove water quality or premium condition.

## Fail-closed
Do not authorize controlled collection when S13.2 has not passed, diversion activation/completion cannot be evidenced, site/event identity is unresolved, required evidence is unavailable, or a material exception remains unresolved.

## Current declaration
No S13.3 live event is claimed by this repository implementation. No first-flush measurement, collection volume, laboratory result or environmental performance value is fabricated.
