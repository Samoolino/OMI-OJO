# S14.2 — Continuous Source, QMS and Release-Scope Health Monitoring

## Purpose
Continuously test whether an authorized release remains supported by its source, QMS, custody, traceability, methodology, regulatory and claim-control records.

## Sequence
1. Confirm the S14.1 monitoring window.
2. Check source availability and provenance.
3. Check QMS/laboratory status and any result corrections.
4. Check custody, batch, container and seal traceability.
5. Check instrument/calibration and methodology/boundary/factor versions.
6. Reconcile the released population and scope.
7. Check product, label, public and investor claim surfaces.
8. Check applicable regulatory authorization conditions.
9. Classify detected changes or anomalies.
10. Assess impact on the authorized release scope.
11. Initiate corrective action or controlled reopening where required.
12. Lock the monitoring record.

## Evidence boundary
A monitoring alert is a control event, not an environmental observation. Source availability is not validity. A QMS correction does not silently overwrite history. Scope changes require controlled assessment.

## Fail-closed
The monitoring state moves to HOLD or controlled corrective action when an untrusted source is used for reporting, material QMS correction is unassessed, traceability is broken, method versions are uncontrolled, release population changes without assessment, claims diverge, regulatory conditions change without review, or security/integrity issues remain unresolved.

## Current declaration
