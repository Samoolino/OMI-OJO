# S13.2 — Rain Event Confirmation & Pre-Event Site Check

## Purpose
Confirm an actual authorized rain event and establish that the physical collection system is ready before first-flush diversion or controlled collection.

This gate does not create a harvest volume, laboratory result, premium determination, or product-release decision.

## Procedure
1. Confirm the unique event identifier and actual event start timestamp.
2. Record an approved weather-source observation with provenance. Forecast data cannot substitute for an observation.
3. Verify the physical collector/site matches the authorized site record.
4. Inspect collector condition, first-flush diversion, measurement devices, video evidence path, visible exceptions and operator readiness.
5. Place the event on HOLD for any material unresolved exception.
6. Preserve evidence classes: forecast, source observation, field operation, readiness/control evidence and synthetic control tests remain distinct.

## Pass condition
Reach SITE_CHECK_PASSED only when the actual event is evidenced, the physical site is reconciled, required controls are available, and no material fail-closed exception remains.

## Current declaration
No S13.2 live event is asserted. No rainfall observation, collection volume, sample, laboratory result or environmental performance value is fabricated.
