# S12 — Institutional Pre-S13 Field Readiness Gate

## Objective
Complete the controlled procedures that must exist and be tested before the first genuinely empirical live rainwater harvest/evidence event.

S12 does not create harvest observations, laboratory results, premium-condition conclusions, regulatory approvals, or product-release evidence.

## Control ladder
DESIGNED → IMPLEMENTED → INTEGRATION_READY → CONTROLLED_TEST → REPORTABLE → VALIDATED → VERIFIED → ANCHORED → RELEASED

## Procedure sequence

1. **S12.1 Site Authorization & Physical Identity**
   - Confirm the actual physical site, authorization, operating boundary and accountable authority.
   - Bind the physical site to DMRV identity.
   - Do not substitute an LCDA, municipality, reporting grid or administrative node for the physical site.

2. **S12.2 Operator & Equipment Qualification**
   - Qualify named roles, competency, escalation and critical equipment.
   - Record responsibility without inventing personnel or equipment evidence.

3. **S12.3 Weather/Telemetry Connector Qualification**
   - Test source identity, timestamps, units, provenance, health and failure behavior.
   - Availability is not evidence validity.

4. **S12.4 Video Evidence Qualification**
   - Test device identity, timestamping, retention, integrity and event linkage.
   - Video is evidence only when linked to a controlled event and provenance.

5. **S12.5 Measurement & Calibration Control**
   - Define instruments, units, calibration/verification requirements and uncertainty handling.
   - No measured value is created by the readiness test.

6. **S12.6 First-Flush & Collection Procedure Qualification**
   - Test the documented diversion and controlled collection procedure.
   - Readiness is not a harvest result.

7. **S12.7 Sampling/Custody/QMS Qualification**
   - Test sample identity, containers, custody transitions, storage and laboratory/QMS handoff.
   - No laboratory result is generated unless an actual controlled sample exists.

8. **S12.8 Batch/Seal Traceability Qualification**
   - Test batch, container/lot, seal and reconciliation identifiers.
   - No production batch is released by this gate.

9. **S12.9 DMRV Event Schema & Methodology Freeze**
   - Freeze mandatory event fields, evidence classes, source provenance, method versions, boundary definitions and lineage rules.

10. **S12.10 Evidence Package Dry Run**
    - Rehearse event assembly using clearly labelled synthetic/control-test records.
    - Hashing proves package integrity only.

11. **S12.11 Anchor Workflow Dry Run**
    - Rehearse the anchor workflow against a synthetic/control-test package.
    - An anchor does not prove environmental truth.

12. **S12.12 Exception/CAPA & Rollback Drill**
    - Exercise sensor outage, conflicting rainfall evidence, custody break, equipment failure and correction/reopening paths.
    - Historical records must not be silently overwritten.

13. **S12.13 External Assurance Evidence-Room Review**
    - Verify prospective reviewer access, evidence indexing, lineage, controls and limitations.
    - Readiness is not an assurance conclusion.

14. **S12.14 Regulatory/Product Compliance Gate**
    - Identify applicable water, environmental, packaging, laboratory, product and other requirements for the intended jurisdiction.
    - Unresolved requirements remain HOLD; do not infer approval.

15. **S12.15 Claims & Investor Surface Freeze**
    - Freeze permissible pre-harvest language.
    - Public and investor surfaces must not imply completed physical production.

16. **S12.16 Integrated Field Readiness Review**
    - Reconcile all preceding gates, open exceptions, owners, evidence and dependencies.
    - Fail closed on any material unresolved dependency.

17. **S12.17 Final Go/No-Go Authorization**
    - Human-authorized decision records whether S13 may begin.
    - Authorization permits an event; it does not validate the future environmental outcome.

## Required S13 transition
Only after S12.17 is authorized may the first controlled empirical sequence begin:

RAIN-EVENT WATCH → EVENT ACTIVATION → PRE-EVENT SITE CHECK → FIRST-FLUSH DIVERSION → CONTROLLED COLLECTION → LIVE MEASUREMENT + VIDEO → SAMPLE IDENTIFICATION → CHAIN OF CUSTODY → QMS/LAB HANDOFF → BATCH + SEAL → DMRV EVENT PACKAGE → EVIDENCE RECONCILIATION → ANCHOR CANDIDATE → ASSURANCE REVIEW → PREMIUM-CONDITION DECISION → REGULATORY/PRODUCT RELEASE GATE

## Fail-closed conditions
- physical site identity or authorization unresolved
- critical operator/equipment qualification incomplete
- untrusted source used as observation
- measurement control absent
- video cannot be linked to the event
- custody/QMS pathway incomplete
- schema or methodology not frozen
- dry run creates or presents synthetic data as real evidence
- material exception/CAPA unresolved
- regulatory/product requirement unresolved where required for the intended activity
- public/investor surface diverges from the authorized evidence state
- human field authorization absent

## Non-equivalences
S12 readiness ≠ harvest.
S12 readiness ≠ environmental performance.
S12 readiness ≠ laboratory result.
S12 readiness ≠ verification.
S12 readiness ≠ certification.
S12 readiness ≠ regulatory approval.
S12 readiness ≠ product release.
