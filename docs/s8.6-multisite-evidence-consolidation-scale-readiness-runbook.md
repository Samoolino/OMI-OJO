# S8.6 — Multisite Evidence Consolidation and Scale Readiness

## Objective
Create a portfolio-level evidence view from independently reviewed sites while preserving site identity, provenance, evidence classes, custody/QMS boundaries and claim scope.

## Consolidation sequence
**PORTFOLIO SCOPE → SITE OUTCOMES → PROVENANCE → EVIDENCE CLASSES → CROSS-SITE CONTROLS → METHODS → QMS/CUSTODY → DMRV VERSION → ANCHORS → CAPA → CLAIMS → SCALE DECISION**

## Core rule
Consolidation is an indexing and reconciliation operation. It is not permission to merge environmental observations into a single unsupported truth.

### Required portfolio controls
- Every record retains site identity and source provenance.
- Missing data is not converted to zero.
- Forecast, modelled, satellite, calculated and proxy values remain explicitly classified.
- Equivalent indicators require documented method/unit/time/scope comparability.
- DMRV schema changes require controlled migration/versioning.
- Site-level conformance outcomes remain immutable within the portfolio view.
- Material exceptions remain visible until resolved.
- Aggregate claims must be reproducible from the underlying site records.

## Scale decision

**SCALE_READY_WITH_CONTROLS** — portfolio controls are adequate for governed continuation within defined scope.

**CONDITIONAL_SCALE_READY** — continuation is permitted only with explicit conditions, owners and due dates.

**HOLD / NOT_READY** — scale promotion stops until material deficiencies are resolved.

None of these states establish product release, potable-water status, premium status, regulatory approval or environmental-performance certification.
