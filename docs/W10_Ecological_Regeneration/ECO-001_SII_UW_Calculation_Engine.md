# ECO-001 — SII-UW Calculation Engine

**State:** S2 — SPECIFIED

## Purpose

Define a versioned methodology for ecological-regeneration scoring associated with Blue-Ether interventions.

## Control model

The engine must keep raw observations separate from normalized scores. Every score must carry a methodology version, observation timestamp, source, reviewer and confidence/data-quality flag.

## Minimum dimensions

- ecological condition;
- water-system contribution;
- biodiversity/ecosystem indicators;
- community/social co-benefits where applicable;
- measurement confidence.

No ecological score is to be presented as an externally verified environmental claim without the corresponding evidence package and review status.
